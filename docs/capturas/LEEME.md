# Capturas para el README y la landing

Los archivos de esta carpeta se usan en el README raíz y en `docs/index.html`.
Ahora son marcadores de posición: **reemplazalos por capturas reales con el mismo
nombre** y quedan publicadas sin tocar código.

| Archivo | Qué mostrar |
|---|---|
| `01-crear-publicacion.png` | Formulario "Nueva publicación" con el título, la dirección escrita y la lista de sugerencias abierta. |
| `02-mapa-direccion.png` | El mismo formulario con el mapa y el pin ya ubicado (después de elegir la sugerencia o tocar el mapa). |
| `03-detalle-ofertas.png` | Detalle de una publicación con 2-3 ofertas y el botón de aceptar. |
| `04-chat.png` | Chat de una oferta con mensajes de ida y vuelta. |

Recomendaciones:

- Capturas de teléfono en vertical, 1080×2340 o similar (la landing las recorta
  en 9:19.5, así que una relación parecida es lo ideal).
- Que no aparezcan datos reales: usar la cuenta de prueba y direcciones
  genéricas.
- Si la captura incluye la barra de estado, no pasa nada; se ve más real.
